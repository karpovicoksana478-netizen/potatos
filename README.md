# 🥔 potatos

Анонимная соцсеть: лента коротких видео и полный набор чатов, групп и каналов.
Один проект, один запуск, ничего платного и ничего лишнего.

---

## ▶ Как запустить (на твоём компьютере)

**Способ 1 — два клика**

```
potatos\start.bat
```

Откроется браузер на http://localhost:8000

**Способ 2 — командная строка**

```
cd "путь\к\Default Project"
python -m uvicorn potatos.app:app --host 0.0.0.0 --port 8000
```

Остановить: `Ctrl+C` в консоли (или закрыть окно `start.bat`).

Чтобы друзья заходили с других устройств — открой у себя порт 8000 в роутере
и раздавай им адрес `http://ТВ_IP:8000`. Проще всего — задеплоить в интернет
(раздел «Деплой» ниже).

## 📱 Что умеет

**Регистрация** — только ник, юзернейм и пароль. Ни почты, ни телефона.
Профиль показывает только то, что ты сам написал.

**Главная (лента)**
- вертикальная лента со свайпом вверх, автовоспроизведение
- лайки (и дабл-тап по экрану), комментарии, сохранение, репост
- кнопка подписки на автора, переход в его профиль по аватарке/юзнейму
- переключатель «Главная / Подписки»
- кнопка звука, счётчик просмотров, бейдж LIVE

**Плюс (создать)**
- 🖼 фото — публикация картинки
- 🎬 видео — публикация ролика из галереи (до 400 МБ)
- 📡 эфир — включает камеру, записывает живое видео и публикует его

**Общение**
- личные чаты, группы и каналы
- поиск сверху по людям, каналам и группам (вступившие скрываются из выдачи)
- создание своей группы или канала кнопкой «＋»
- текст, фото, видео и стикеры-эмодзи
- сообщения приходят мгновенно (WebSocket), с индикатором «печатает…»
- непрочитанные, счётчики, ссылка-приглашение, участники
- в канале публикует владелец и администраторы, в группе — все участники
- долгое нажатие (или правая кнопка мыши) на сообщении — удалить своё;
  админ/владелец может удалить чужое, админ не трогает сообщения владельца

**Роли в группе и канале**
- владелец: всё, в том числе назначение админов, удаление чата
- админ: фото, название, описание, добавление и исключение участников
- админ не может: удалить чат, менять права других админов, трогать владельца
- простой участник: читает, пишет (в группе), выходит

**Настройки (шестерёнка в профиле)**
- тёмная и светлая тема — переключается сразу, запоминается на устройстве
- редактирование профиля, выход из аккаунта

**Группа: «Настроить»**
- фото, название, описание — как в профиле
- управление участниками: назначить/снять админа, удалить из чата
- ссылка-приглашение и удаление чата (только владелец)

**Профиль**
- аватар, ник, юзернейм, описание — всё редактируется
- вкладки: Видео / Репосты / Сохранённые / Лайки
- кружочки с аватарками подписчиков
- у чужого профиля — «Подписаться» и «Написать»
- перейти в профиль можно из ленты, из комментариев и из переписки

## 🗂 Структура проекта

```
potatos/
  app.py          — запуск сервера, страница-оболочка, WebSocket
  db.py           — база данных SQLite и таблицы
  auth.py         — пароли (хеширование) и токены входа
  users.py        — регистрация, вход, профили, подписки, поиск
  videos.py       — лента, публикации, лайки, комменты, репосты
  chats.py        — чаты, группы, каналы, сообщения
  hub.py          — доставка сообщений в реальном времени
  static/
    index.html    — оболочка приложения
    app.js        — ядро: роутер, вход, WebSocket, навигация
    feed.js       — лента и экран «+»
    chats.js      — общение
    profile.js    — профиль
    style.css     — оформление
    sw.js         — офлайн-режим (PWA)
    icon-*.png    — иконка-картошка 🥔
  media/          — загруженные фото, видео, аватары (создаётся само)
  potatos.db      — база данных (создаётся само)
  smoke_test.py   — 74 проверки API
  ws_test.py      — тест реального времени
  browser_test.py — 37 тестов интерфейса в настоящем браузере
  js_check.py     — синтаксическая проверка всех JS-файлов
  make_icon.py    — перегенерация иконок
```
